# Responder consulta técnica o funcional

## Objetivo

Responder una pregunta puntual usando solamente las fuentes necesarias y distinguiendo hechos, inferencias e incertidumbres.

## Precondiciones

- La pregunta está delimitada.
- Se puede consultar código, `.sdd/context/`, specs, work items y documentación relevante.

## Resultado

Entregar una respuesta directa con referencias concretas cuando aporten valor. No crear un work item salvo que la consulta derive en un cambio gobernado ni documentar archivos nuevos si el usuario no lo solicita.
