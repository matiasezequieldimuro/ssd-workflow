# Implementar cambio aprobado

## Objetivo

Aplicar el plan aprobado y registrar fielmente lo realizado.

## Precondiciones

- El motor habilitó la fase `implementation` tras aprobar el plan.
- El adaptador obtuvo los permisos de escritura necesarios.

## Resultado

Modificar únicamente el alcance autorizado. Crear `artifacts/implementation-report.md` con cambios, archivos relevantes, pruebas y cualquier desviación aprobada. No marcar una fase como completada: esa transición la realiza el motor.
