# Documentar proyecto existente

## Objetivo

Construir contexto estable y verificable de un repositorio existente para reducir exploraciones repetidas.

## Precondiciones

- El contrato SDD está inicializado.
- Se dispone del código y de la documentación del proyecto.
- Las fuentes faltantes o contradictorias pueden declararse explícitamente.

## Resultado

Actualizar los documentos aplicables bajo `.sdd/context/`: proyecto, arquitectura de software, arquitectura del proyecto, modelado de datos, flujo de datos y lenguaje de dominio. Priorizar el codebase para detalles de implementación y no inventar contexto de plataforma ausente.
