# Archivar work item

## Objetivo

Cerrar un work item ya revisado, consolidando el conocimiento durable y preservando su expediente.

## Precondiciones

- La revisión humana de código está aprobada.
- Las acciones externas necesarias fueron autorizadas explícitamente.

## Resultado

Crear `artifacts/archive.md`, registrar la consolidación de baseline/changelog y solicitar al motor el archive. Commit, push o PR son acciones separadas y nunca se infieren.
